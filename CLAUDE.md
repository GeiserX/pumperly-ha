# CLAUDE.md — pumperly-ha

## Overview
Home Assistant custom integration that tracks real-time fuel and EV charging prices from a Pumperly instance, providing sensors for cheapest, nearest, and average prices with configurable search radius across 36 countries.

## Tech Stack
- Python
- Home Assistant custom component API
- HACS compatible
- pytest (test suite)
- GitHub Actions CI (validation + tests)

## Development
